Rclone Backup Pessoal

O Rclone Backup Pessoal é uma configuração de uso individual do programa de código aberto Rclone para transferir arquivos e pastas selecionados do computador do próprio usuário para a conta Google Drive que ele autorizar.

Como funciona

A transferência é iniciada localmente no computador do usuário. O Rclone se conecta ao Google Drive por meio da API oficial do Google e da autorização OAuth concedida pelo titular da conta. Os arquivos são enviados diretamente do computador para o Google Drive autorizado.

Dados acessados

O aplicativo solicita o escopo drive.file, que limita o acesso aos arquivos e pastas criados ou disponibilizados para este aplicativo. O acesso é utilizado para criar pastas, enviar arquivos e consultar os itens que o próprio aplicativo pode acessar, de modo a apoiar a transferência e sua conferência.

Armazenamento e compartilhamento

O conteúdo dos arquivos não é enviado para um servidor operado pelo responsável por esta configuração. A transferência ocorre entre o computador do usuário e a infraestrutura do Google Drive. O responsável por esta configuração não recebe, armazena, vende ou compartilha os arquivos do usuário.

Controle do usuário

O usuário escolhe quais pastas e arquivos deseja transferir e pode revogar a autorização concedida ao aplicativo nas configurações de segurança da Conta Google. O usuário deve proteger o próprio computador e os arquivos locais de configuração do Rclone, pois eles podem conter tokens de autorização.

Privacidade

Leia a Política de Privacidade para obter detalhes sobre o acesso e o tratamento dos dados.

Contato

Para dúvidas sobre esta configuração, entre em contato pelo endereço informado na tela de consentimento OAuth do aplicativo.
